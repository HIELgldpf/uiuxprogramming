# 마인크래프트 스피드런 가이드

## 1. 서비스 소개

마인크래프트 스피드런을 처음 접하는 사용자가 기본 정보와 진행 방법을 확인할 수 있는 웹페이지입니다.

## 2. 주요 사용자

마인크래프트 스피드런을 처음 시작하거나 연습 방법을 알고 싶은 사용자입니다.

## 3. 서비스 목적

스피드런의 기본 규칙과 진행 과정을 소개하고, 사용자가 자신의 연습 종목과 숙련도에 맞는 연습 방향을 확인할 수 있도록 합니다.

## 4. 핵심 행동과 완료 조건

- 핵심 행동: 연습 종목과 숙련도를 선택하고 연습 안내를 확인하기
- 추가 행동: 완료한 연습 계획을 저장하고 다시 불러오거나 삭제하기
- 추가 행동: 의견 유형과 내용을 입력하고 의견 제출하기
- 완료 조건: 선택한 정보가 결과에 표시되고 저장한 계획을 목록에서 관리할 수 있습니다.
- 폼 완료 조건: 필수 입력값과 입력 형식이 올바른 경우 의견을 제출할 수 있습니다.

## 5. 사용자 흐름

1. 연습 시작 버튼을 누릅니다.
2. 스피드런 종목, 버전, 숙련도를 선택합니다.
3. 선택한 정보를 확인합니다.
4. 연습 안내를 확인합니다.
5. 연습 목록에 저장 버튼을 눌러 계획을 저장합니다.
6. 저장된 계획을 불러오거나 삭제합니다.
7. 다시 시작 버튼으로 선택 흐름을 초기화합니다.
8. 의견 남기기 영역에서 의견 유형과 내용을 입력합니다.
9. 필요한 경우 이메일 입력을 선택하고 이메일을 입력합니다.
10. 입력값을 확인한 후 의견을 제출합니다.

## 6. 중간고사 신규 기능

기존 연습 준비 완료 화면에 연습 계획 저장 기능을 추가했습니다.

저장한 계획은 목록에 표시되며, 다시 불러오거나 삭제할 수 있습니다. localStorage를 사용하여 새로고침 후에도 계획이 유지되도록 구현했습니다.

### 새 기능의 인터랙션 시나리오

- 연습 안내 완료 → 연습 목록에 저장 버튼 클릭
- 저장 조건 검사 → 종목, 버전, 숙련도 확인
- 저장 성공 → 연습 목록에 새 계획 표시
- 중복 저장 → 이미 저장된 계획이라는 안내 표시
- 불러오기 → 저장된 종목, 버전, 숙련도를 선택 화면에 복원
- 삭제 → 목록에서 해당 계획 제거
- 목록이 비어 있음 → 저장된 계획이 없다는 안내 표시
- 저장 공간 오류 → 저장 또는 삭제에 실패했다는 안내 표시

## 7. 9주차 신규 기능

기존 의견 남기기 폼을 개선하여 사용자가 입력하는 과정에서 오류를 확인하고 수정할 수 있도록 구현했습니다.

입력 항목에 라벨과 안내 문구를 제공하고, 의견 유형 선택 및 추가 이메일 입력 기능을 추가했습니다.

### 새 기능의 인터랙션 시나리오

- 의견 유형 선택 → 사용자가 의견 유형을 선택
- 의견 입력 → 의견 내용을 입력
- 추가 이메일 입력 선택 → 체크박스 선택 시 이메일 입력란 표시
- 체크 해제 → 이메일 입력란 비활성화
- 입력값 검사 → 필수 항목 및 이메일 형식 확인
- 입력 오류 → 해당 입력 항목에 오류 메시지 표시
- 입력값 수정 → 오류 조건이 해결되면 오류 메시지 제거
- 제출 중 → 제출 버튼 비활성화로 중복 제출 방지
- 제출 성공 → 성공 메시지 표시 및 입력 폼 초기화
- 제출 실패 → 실패 메시지 표시 및 기존 입력값 유지

## 8. 테스트 기록

- [O] 연습 계획을 정상적으로 저장할 수 있는지 확인

- [O] 저장한 계획을 다시 불러오면 선택값이 복원되는지 확인
- [O] 저장한 계획을 삭제하면 목록에서 사라지는지 확인
- [O] 모든 계획을 삭제하면 빈 목록 안내가 표시되는지 확인
- [O] 새로고침 후에도 저장한 계획이 유지되는지 확인

- [O] 입력값을 수정하면 오류 메시지가 사라지는지 확인
- [O] 체크박스 선택 시 이메일 입력란이 표시되는지 확인

- [O] 잘못된 입력 상태에서 제출이 차단되는지 확인
- [O] 제출 중 버튼이 비활성화되어 중복 제출이 방지되는지 확인
