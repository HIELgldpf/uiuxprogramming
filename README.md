# 마인크래프트 스피드런 가이드

## 1. 서비스 소개
마인크래프트 스피드런을 처음 접하는 사용자가
기본 정보와 진행 방법을 확인할 수 있는 웹페이지입니다.

## 2. 주요 사용자
마인크래프트 스피드런을 처음 시작하거나
연습 방법을 알고 싶은 사용자입니다.

## 3. 서비스 목적
스피드런의 기본 규칙과 진행 과정을 소개하고,
사용자가 자신의 연습 종목과 숙련도에 맞는
연습 방향을 확인할 수 있도록 합니다.

## 4. 핵심 행동과 완료 조건
- 핵심 행동: 연습 종목과 숙련도를 선택하고 결과 확인하기
- 완료 조건: 선택한 정보가 확인 화면과 완료 화면에 표시되고
  해당 선택에 맞는 연습 안내를 확인하는 것입니다.

## 5. 사용자 흐름
1. 연습 시작 버튼을 누릅니다.
2. 스피드런 종목과 현재 숙련도를 선택합니다.
3. 선택한 정보를 확인합니다.
4. 이전 단계에서 수정하거나 확인을 눌러 완료합니다.
5. 다시 시작 버튼으로 입력값과 진행 상태를 초기화합니다.

## 6. 인터랙션 시나리오
- 시작 버튼 클릭 → 선택 화면 표시
- 종목 변경 → 종목에 맞는 설명 표시
- 필수 선택 누락 → 오류 메시지 표시
- 선택 확인 → 선택값을 확인 화면에 표시
- 이전 버튼 클릭 → 기존 선택값을 유지한 채 선택 화면으로 이동
- 완료 버튼 클릭 → 선택값에 맞는 연습 안내 표시
- 다시 시작 클릭 → 선택값과 오류 및 진행 상태 초기화

## 7. 테스트 결과
- [ ] 시작부터 완료까지 정상적으로 진행되는지 확인
- [ ] 종목을 선택하지 않았을 때 오류가 표시되는지 확인
- [ ] 숙련도를 선택하지 않았을 때 오류가 표시되는지 확인
- [ ] 이전 단계로 돌아가도 선택값이 유지되는지 확인
- [ ] 값을 수정한 뒤 확인 화면에 변경 내용이 반영되는지 확인
- [ ] 다시 시작하면 선택값과 진행 상태가 초기화되는지 확인
- [ ] 모바일 화면에서 버튼과 선택 항목이 잘리지 않는지 확인
- [ ] 기존 탭 전환 및 의견 제출 기능이 정상 작동하는지 확인
